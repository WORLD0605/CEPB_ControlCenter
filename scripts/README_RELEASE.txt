CEPB Control Center
===================

版本号: 见程序窗口底部右下角（例如 v0.9）

运行方式
--------
直接双击 "CEPB_ControlCenter.exe" 即可运行，无需安装。

系统要求
--------
- Windows 10 / Windows 11
- 64 位操作系统

功能简介
--------
- 调试控制: 通过 TCP 连接现场设备调试控制台，执行命令和查看实时数据。
- 配置概览: 导入工程配置，查看模型和设备列表。
- 模型编辑器: 编辑 IEC 61850 模型模板及点位信息。
- 104 设备编辑器: 编辑 IEC 104 设备实例及点位地址绑定。
- 配置上传/下载: 通过 SSH/SCP 批量上传或下载设备配置。

配置上传/下载说明
------------------
- 设备密码默认按 root 处理，可在配置概览页修改。
- 上传会先清空设备内对应配置目录，再写入当前工作区配置；上传前请先自行备份设备内原配置。
- 上传/下载过程中会显示当前阶段和正在处理的文件名。
- 下载解包按 UTF-8 解释文件名，适配包含中文文件名的模型和设备配置。
- 需要密码登录的设备，程序会优先使用随包 tools 目录或程序目录中的 plink.exe、pscp.exe；也支持使用 PATH 中的 PuTTY 工具。
- 如果没有 plink/pscp，程序不会尝试密码登录；系统 ssh/scp 仅用于已配置 SSH key 的设备。
- 使用系统 ssh/scp 时会禁用交互式密码提示，并自动接受首次连接的新设备 host key，避免界面卡住。
