CEPB Control Center
===================

版本号：见程序窗口底部右下角，例如 v0.9。

运行方式
--------
直接双击 `CEPB_ControlCenter.exe` 即可运行，无需安装。

系统要求
--------
- Windows 10 / Windows 11
- 64 位操作系统

功能简介
--------
- 调试控制：通过 TCP 连接现场设备调试控制台，执行命令并查看实时数据。
- APP管理：通过内置 SSH 管理设备端服务启停、重启和开机自启。
- 配置概览：导入工程配置，查看模型和设备列表。
- 模型编辑器：编辑 IEC 61850 模型模板及点位信息。
- 设备编辑器：编辑 IEC 104 / Modbus 等设备实例及点位绑定。
- 配置上传/下载：通过内置 SSH/SCP 批量上传或下载设备配置。

设备连接
--------
- 程序右上角统一填写设备 IP。
- SSH 固定端口：10022。
- SSH 固定用户名：root。
- SSH 固定密码：root。
- 程序已内置 SSH/SCP 能力，不依赖 Windows 自带 ssh/scp，也不需要 PuTTY 的 plink.exe/pscp.exe。

配置上传/下载说明
------------------
- 上传会先清空设备内对应配置目录，再写入当前工作区配置；上传前请先自行备份设备内原配置。
- 上传/下载过程中会显示当前阶段。
- 下载后会自动解包并重新导入配置。
- 本地解包按 UTF-8 解释文件名，适配包含中文文件名的模型和设备配置。
