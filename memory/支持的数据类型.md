当前代码实际支持的 ini 类型如下。

**YX 遥信**
`yx_type` / `yx_type1` / `yx_type2` 支持：

```ini
BIT
POCKETBIT
```

默认是：

```ini
yx_type=BIT
```

虽然代码类型表里也有 `WORD/FLOAT/...`，但遥信通常配功能码 `1` 或 `2`，也就是读线圈/离散输入，实际建议只用 `BIT`。`POCKETBIT` 目前和 `BIT` 解析逻辑一样。

**YC 遥测**
`yc_type` / `yc_type1` / `yc_type2` 支持：

```ini
WORD
UNSIGNED_WORD
FLOAT
FLOAT_L
DWORD
DWORD_L
```

默认是：

```ini
yc_type=WORD
```

含义大概是：

```text
WORD           1个寄存器，有符号16位
UNSIGNED_WORD  1个寄存器，无符号16位
FLOAT          2个寄存器，浮点数，当前代码按一种字节序解析
FLOAT_L        2个寄存器，浮点数，高低寄存器反序
DWORD          2个寄存器，32位整数
DWORD_L        2个寄存器，32位整数，高低寄存器反序
```

**YK 遥控**
这里要注意：**当前代码没有读取 `yk_type` 配置**。

在 [promodbusprivate.cpp](./promodbusprivate.cpp:326) 里写死了：

```cpp
m_sdata.mtype = "WORD";
```

所以现在 `yk_set1` 只能按 `WORD` 处理。你在 ini 里写：

```ini
yk_type=...
yk_type1=...
```

当前程序不会用。

**YT 遥调**
`yt_type` / `yt_type1` / `yt_type2` 支持：

```ini
WORD
FLOAT
FLOAT_L
DWORD
DWORD_L
```

默认是：

```ini
yt_type=WORD
```

从写入代码看，`WORD` 写 1 个寄存器，其他类型默认写 2 个寄存器。`UNSIGNED_WORD` 虽然读数据支持，但写入分支里没有单独处理，所以 **YT 不建议配 `UNSIGNED_WORD`**，目前可靠的是上面这 5 个。

简单总结：

```text
yx_type: BIT, POCKETBIT
yc_type: WORD, UNSIGNED_WORD, FLOAT, FLOAT_L, DWORD, DWORD_L
yk_type: 当前不支持配置，写死 WORD
yt_type: WORD, FLOAT, FLOAT_L, DWORD, DWORD_L
```
