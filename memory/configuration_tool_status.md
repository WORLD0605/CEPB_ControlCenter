## 当前进度

已完成：

1. 工程目录导入与导出闭环，104 与 Modbus 按协议分别导出到 `cepiec104`、`cepmodbus`。
2. 模型列表、模型编辑器、设备编辑器基础界面，以及模型/设备双击进入编辑器交互。
3. 模型点位新增、复制、删除，DataRef 实时校验。
4. 104 设备基础字段、点位地址绑定、自发标志勾选导出。
5. Modbus 设备编辑器：
   - 支持 RTU/TCP 参数编辑，串口、波特率、数据位、停止位、校验位均为下拉选项。
   - 支持硬件型号 `myir/talowe`，用于 `RS485_4` 的 `hw_variant` 导出。
   - 支持点位填写寄存器地址、功能码、数据类型、比例、点位类型。
   - 自动生成轮询/写入分组、组内序号和 `dataIndex`。
   - 点位类型以中文下拉展示：遥信、遥测、遥控、遥调。
   - 自发标志改为勾选框，勾选后导出 `self_sig_flag=1`。
6. 从模型创建设备时可选择 104 或 Modbus；Modbus 默认参数为 `RTU / RS485_1 / 9600 / 8 / 1 / N`。
7. Modbus Control 点自动分类规则：`Boolean`、`DBool` 生成遥控，其余 Control 类型生成遥调。
8. 模型导出补齐 service 级字段：`description` 和 `serviceId`。
9. 配置概览页支持删除模型和删除设备；删除模型时会提示并级联删除引用该模型的设备。
10. 导出前会清理对应协议目录下 `model/*.json` 和 `dev/*.json` 旧文件，避免 UI 删除后旧文件残留。

## 当前边界

当前主要能力已覆盖 `cepiec104` 与 `cepmodbus` 的模型、设备、Modbus ini 配置编辑与导出。

`cepdlt645`、`cepLogicCenter` 仍主要处于目录结构预留状态，尚未接入完整导入、编辑和导出能力。
