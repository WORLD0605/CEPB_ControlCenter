## 当前进度

已完成：

1. 工程目录导入与导出闭环，104 与 Modbus 按协议分别导出到 `cepiec104`、`cepmodbus`。
2. 模型列表、模型编辑器、设备编辑器基础界面，以及模型/设备双击进入编辑器交互。
3. 模型点位新增、复制、删除，DataRef 实时校验。
4. 104 设备基础字段、点位地址绑定、自发标志勾选导出。
5. Modbus 设备编辑器：
   - 支持 RTU/TCP 参数编辑，串口、波特率、数据位、停止位、校验位均为下拉选项。
   - 支持硬件型号 `myir/talowe`，用于 `RS485_4` 的 `hw_variant` 导出。
   - 支持点位填写寄存器地址、功能码、数据类型、比例、点位类型。
   - 自动生成轮询/写入分组、组内序号和 `dataIndex`。
   - 点位类型以中文下拉展示：遥信、遥测、遥控、遥调。
   - 自发标志改为勾选框，勾选后导出 `self_sig_flag=1`。
6. 从模型创建设备时可选择 104 或 Modbus；Modbus 默认参数为 `RTU / RS485_1 / 9600 / 8 / 1 / N`。
7. Modbus Control 点自动分类规则：`Boolean`、`DBool` 生成遥控，其余 Control 类型生成遥调。
8. 模型导出补齐 service 级字段：`description` 和 `serviceId`。
9. 配置概览页支持删除模型和删除设备；删除模型时会提示并级联删除引用该模型的设备。
10. 导出前会清理对应协议目录下 `model/*.json` 和 `dev/*.json` 旧文件，避免 UI 删除后旧文件残留。
   导入/导出问题统一进入“问题列表”页签，导出警告不再用长弹窗展示；双击问题行会尽量跳转到对应模型、设备或 LogicCenter 编辑页面。
11. LogicCenter 可视化配置已完成阶段 1-8：
   - 支持 `LogicCenter_Config.json` 结构化导入、导出和未知字段保留。
   - 支持 LogicCenter 总览、校验问题展示、AGC/AVC 单虚拟并网点配置。
   - 支持计算点模板生成和计算点列表维护。
   - 支持控制转换编辑器：按源设备/源控制点维护 `control_rules`，目标动作支持 `ctrlcmd`/`data_write`、公式模板、实时值引用插入和表达式展开预览。
   - `CtrlType` 不在控制转换编辑器中展示，也不从配置工具导出；运行态复用北向 `CtrlCmd` 帧中的 `CtrlType`。
   - 支持在线状态联动编辑器：维护 `onlineStatus_link`，支持设备列表选择、新增删除，以及虚拟设备/派生设备跟随真实设备的快捷生成。
12. 配置上传/下载第一版：
   - 配置概览页可填写设备地址、用户、密码、端口和远端 APP 根目录，密码默认 `root`。
   - 上传前会提示用户先自行备份设备内配置，并在确认后清空远端对应配置目录再上传当前工作区配置。
   - 下载时选择本地目录，批量拉取远端配置并自动重新导入为当前工作区。
   - 优先使用 `plink/pscp -pw` 支持密码登录；未安装 PuTTY 工具时回退到系统 `ssh/scp`，适合 SSH key 场景。
   - 上传/下载过程中显示阶段进度和正在处理的文件名；本地解包按 UTF-8 解释 tar 文件名，避免中文文件名乱码。

## 当前边界

当前主要能力已覆盖 `cepiec104`、`cepmodbus` 的模型/设备配置，以及 `cepLogicCenter`
的 AGC/AVC、计算点、控制转换、在线联动配置，并支持通过 SSH/SCP 上传和下载配置。

`cepdlt645` 尚未接入完整导入、编辑和导出能力。LogicCenter 的虚拟设备派生、
高级 JSON 预览仍待后续阶段补齐。
